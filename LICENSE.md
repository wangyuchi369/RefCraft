# License status

The release license for the project's original code and original annotations
has not yet been selected by the project owner. This directory is prepared for
release; it does not invent a license grant or alter existing third-party terms.

Third-party reference webpages retain their original licenses and attribution.
See `docs/attribution.md` for the original reference-pool attribution and
`data/attribution.json` for the exact 534 source-page mappings used
by this subset. The original attribution document describes the larger pool;
the machine-readable subset mapping identifies the sources actually used here.

Metadata lists 83 MIT and 32 CC BY 3.0 source pages. The remaining 419 have no
third-party license field in the source metadata; their source type is preserved
individually, not silently relicensed. Existing linked license and author fields
are retained. Decide the original-code/annotation license before public release.
