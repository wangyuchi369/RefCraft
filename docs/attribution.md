# 参考页库的来源与许可

744 页参考页分两批入库，署名与许可按批列在下面（族名即 `meta.json` 的族字段）。
所有第三方页均按各自开放许可再分发；许可正文在入库时逐 repo 取回核对过 SPDX，
没有 LICENSE 的源一律不收。

---

## 第一批（id 1–500）


500 页参考页里，200 页取自开放许可的第三方网页模板，按各自许可再分发；其余 300 页是本项目自己生成的页面，不涉及第三方许可。
